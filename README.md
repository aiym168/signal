# AI 羊毛信号站 · https://yangmao.devis.im/

24 小时不停播的 AI 羊毛直播站：整点快讯、早晚报轮播、实时字幕，以及每 5 分钟实测一次的大模型 API 网关雷达。

这个仓库只放网页本身（GitHub Pages）；直播流和雷达数据由信号站后端实时提供，
网页通过 <https://aiym168.github.io/api/live.json> 找到后端当前地址。
